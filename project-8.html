01

Features & Capabilities

📡
Real-Time Acquisition

12-bit ADC at ~200 kSps with 3.3 V reference gives 0.8 mV resolution. 320-sample circular buffer feeds the waveform engine.

🔋
TP4056 Battery System NEW

Integrated USB-C charging via TP4056 module with protection IC. Supports 3.7 V LiPo cells, charge status LEDs, over-discharge guard.

v3
🖥️
ILI9341 TFT Display

2.8″ 240×320 SPI colour display in landscape mode. Green waveform, orange status, dotted grid — all rendered at native pixel depth.

⚡
Power Switch

Dedicated SPDT slide switch between the TP4056 output and VSYS. Clean power-on/off without floating lines or battery drain.

v3
📏
10 Voltage Ranges

0.2 V to 50 V/div (with ×10 probe). Auto-range modes A50V and A5V for hands-free signal tracking across unknown sources.

⏱️
10 Timebases

50 µs to 50 ms per division. Adaptive timing delay in the ADC acquisition loop ensures accurate time-per-sample at every setting.

🎯
Edge Trigger

Rising and falling edge trigger modes with visual SYN indicator. Trigger point is located algorithmically in the sample buffer post-capture.

🧪
1 kHz Test Signal

GP15 outputs a 1 kHz square wave via hardware PWM — zero external hardware needed to verify probe, display, and triggering at power-on.

🔗
STEP File Included

Download the oscilloscope.step file for 3D CAD viewing, modification, or printing your own enclosure.

🛡️
Input Protection

Input protection diodes and series resistors safeguard the ADC and main board from accidental overvoltage.

🧰
Open Source Firmware

Fully open-source firmware for customization, upgrades, and community-driven improvements.

01 First Power-On
+
  • Charge LiPo via USB-C — red LED = charging, green/blue = full
  • Flip power switch to ON
  • Display initialises, status bar shows V:5V H:5ms Rise
  • Connect GP15 (test sig) to GP26 (probe IN) with a jumper wire
  • You should see a clean 1 kHz square wave immediately
02 Measuring a Signal
+
  • Connect probe tip to signal, probe GND clip to circuit GND
  • Press MODE until V/div is yellow — press UP/DOWN to set range
  • Press MODE for H/div — adjust timebase to capture waveform
  • Press MODE for Trigger — UP = rising, DOWN = falling
  • Average voltage shows live in the status bar top-right
03 Using Auto-Range
+
  • Scroll V/div UP past 5V to reach A5V (auto 0–5V)
  • Continue UP to A50V (auto 0–50V with ×10 probe)
  • Auto-range adjusts scale automatically as signal amplitude changes
  • Switch back to fixed range for precision measurements
04 Hold / Freeze Mode
+
  • Press HOLD once — waveform freezes, HLD appears in orange
  • Examine the static trace — count divisions, estimate period
  • STATUS bar remains live even in hold mode
  • Press HOLD again to resume live acquisition
05 Calibration Procedure
+
  • ADC Offset: Connect GP26 to GND. Note rawAve in Serial Monitor. Set adcOffset = that value.
  • ADC LSB: Connect GP26 to 3.3V. Note displayed V. Set lsb5V = 0.000806 × (3.300 / displayed_V).
  • Re-upload firmware after each change.
  • Open Serial at 115200 baud to observe debug output.
06 Charging the Battery
+
  • Plug any USB-C cable — TP4056 red LED turns on (charging)
  • Green/blue LED indicates full charge (~4.2V)
  • Can charge with power switch in ON or OFF position
  • Never leave LiPo charging unattended for extended periods
  • If battery feels warm during charge, reduce RPROG current

Code & Environment Setup

01

Install Arduino IDE 2.x

Download from arduino.cc/en/software. Version 2.x required for library manager compatibility. Install for your OS (Windows/Linux/macOS).

02

Add RP2040 Board Package

Go to File → Preferences → Additional Board URLs and add:
https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json

03

Install Core via Board Manager

Tools → Board → Board Manager → search "RP2040". Install Raspberry Pi Pico/RP2040 by Earle Philhower. Version 3.x+ recommended.

04

Select Board & Port

Tools → Board → Raspberry Pi RP2040 Boards → Raspberry Pi Pico 2. After connecting USB: Tools → Port → select the COM/tty port that appears.

ℹ️ Install all libraries via Sketch → Include Library → Manage Libraries. Search by exact name.

// Pocket Oscilloscope v3 — Key Definitions
#include <SPI.h>
#include <Adafruit_GFX.h>
#include <Adafruit_ILI9341.h>

// ── Display Pins (SPI0 default) ──
#define TFT_CS   17   // Chip Select
#define TFT_DC   21   // Data/Command
#define TFT_RST  20   // Reset
// MOSI=GP19, SCK=GP18 (SPI0 default)

// ── ADC & Probe ──
#define ADC_PIN  26   // GP26 = ADC0
#define TEST_PIN 15   // 1kHz PWM output

// ── Calibration Constants ──
float lsb5V    = 0.000806;  // 3.3V / 4096
int   adcOffset = 0;        // Zero calibration

// ── Display Init ──
Adafruit_ILI9341 tft = Adafruit_ILI9341(TFT_CS, TFT_DC, TFT_RST);

void setup() {
  tft.begin();
  tft.setRotation(3);  // Landscape
  
  // PWM test signal
  analogWriteFreq(1000);   // Philhower core
  analogWrite(TEST_PIN, 128);
  
  // Buttons with internal pull-up
  pinMode(0, INPUT_PULLUP);
  pinMode(1, INPUT_PULLUP);
  pinMode(2, INPUT_PULLUP);
  pinMode(3, INPUT_PULLUP);
}
A

ADC Offset — Zero Calibration

Short GP26 directly to GND. Open Serial Monitor at 115200 baud. Note the rawAve: value printed. Set adcOffset = rawAve_value in code. Re-upload.

B

ADC LSB — Voltage Scale

Connect GP26 to the Pico's 3.3V pin (pin 36). Note the average voltage on screen. If it shows X volts: lsb5V = 0.000806 × (3.300 / X). Re-upload and verify.

C

Pull-Down Resistor (Hardware)

Add a 10 kΩ resistor from GP26 to GND on the probe input. This prevents a floating ADC pin from reading garbage (~6.6 V with no signal connected).

01

Open Project Sketch

File → Open → select PocketOscilloscope_v3.ino. Ensure all tabs (if multi-file) are present in the same folder.

02

Verify / Compile

Press the ✓ Verify button. Should compile with 0 errors. If you see dtostrf errors — ensure you're on Philhower core, not Mbed. The v3 code uses sprintf for ARM compatibility.

03

Hold BOOTSEL & Flash

Hold the BOOTSEL button on the Pico while connecting USB. A drive called RPI-RP2 appears. Press Upload in Arduino IDE — it flashes automatically via UF2 bootloader.

04

Verify Serial Output

Open Serial Monitor at 115200 baud. You should see continuous rawAve: XX and avgV: X.XXV debug lines confirming the ADC is running.

✅ Build verified on Earle Philhower RP2040 core v3.x. Conditional compile macros handle Mbed OS compatibility automatically if you switch cores.
